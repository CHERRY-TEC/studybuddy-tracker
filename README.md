# StudyBuddy Tracker

A single-page web app for two friends to track study and daily activities, with sync, gamification, chat, and analytics features.

## Features

- **Dashboard** — Stats, weekly chart, activity log, daily target
- **Timer** — Study timer, Pomodoro, Focus Mode, session history
- **Goals** — Weekly goals with progress tracking
- **Analytics** — Productivity score, subject breakdown, leaderboard
- **Chat** — Real-time chat with emoji reactions
- **XP & Gamification** — Levels, badges, daily challenges, streak freeze
- **Reminders** — Study reminders with browser notifications
- **Friends** — Friend code system for remote sync
- **Export** — Download reports as TXT, JSON, or CSV
- **Themes** — Dark and light mode toggle

## Live Demo

[https://cherry-tec.github.io/studybuddy-tracker](https://cherry-tec.github.io/studybuddy-tracker)

## Usage

1. Open `index.html` in a browser
2. Share your 6-digit friend code with your study partner
3. Log activities, track goals, and compete on the leaderboard

## Tech Stack

- Single HTML file with embedded CSS and JS
- LocalStorage for persistence
- No external dependencies
